# Panduan Kontribusi

Proyek masih berada pada tahap perencanaan.

- Diskusikan perubahan besar melalui issue sebelum implementasi.
- Jelaskan masalah yang ingin diselesaikan dan cara menguji perubahan.
- Jangan commit token, password, file environment, atau data pribadi.
- Gunakan data dummy untuk pengembangan dan screenshot.
- Hindari menambahkan dependency sebelum kebutuhan dan dampaknya jelas.
- Hormati kebijakan sekolah dan jangan menganggap data atau aset sekolah bebas dipublikasikan.
- Lisensi dan model kontribusi final akan ditentukan setelah kepemilikan proyek dikonfirmasi.
