# Draft Kontrak API

Belum ada endpoint yang diimplementasikan. Ini daftar domain API yang perlu dirancang setelah model data disepakati.

- Auth dan sesi pengguna
- Katalog, detail buku, filter, dan pengurutan
- Kategori dan metadata
- Anggota
- Eksemplar dan ketersediaan
- Peminjaman, pengembalian, dan riwayat
- Laporan
- Pencarian bahasa alami untuk AI

Setiap endpoint perlu mendefinisikan skema request/response, autentikasi, role yang diizinkan, validasi, pagination, dan format error. Jangan anggap dokumen ini sebagai API yang sudah aktif.
