# Strategi Pengujian

Pengujian yang direncanakan:
- Unit test untuk aturan stok dan transaksi.
- Integration test untuk API dan database.
- Authorization test untuk setiap role.
- Regression test untuk filter dan pengurutan katalog.
- AI evaluation test untuk memastikan jawaban hanya merujuk hasil katalog terverifikasi.
- Backup dan restore test sebelum penggunaan nyata.

Gunakan data dummy, bukan data siswa atau guru sungguhan.
